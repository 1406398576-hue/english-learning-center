# English Learning Center（Lululab 学习中心）

个人英语学习资产中心 —— 把「每日阅读」「每日口语」「每日美剧台词」三类自动化学习内容归档成网页，并在其上沉淀出个人表达资产库与阅读积累。

> 本项目为个人学习工具。仓库内容含少量影视剧台词短语引用与英文原版书全文（仅个人学习使用），请勿用于商业分发。

## 功能

- **每日阅读 / 每日口语 / 美剧台词**：按日期归档的每日学习内容，可搜索、按来源筛选（`manifest.jsonl` 实时索引，离线时回退内嵌数据）。
- **我的表达（个人表达资产库）**：从阅读、影视、口语中收藏的地道表达，带中文理解 / 来源 / 使用场景 / 我的理解 / 我的例句，支持「学习中 → 已掌握」状态管理。
- **100 核心句型**：内置 5 组常用句型库（描述自己 / 观点 / 日常交流 / 经历故事 / 情绪），每条含句式模板、例句、替换练习，可一键加入个人表达。
- **阅读积累中心**：7 本英文原版书在线阅读，选中即收藏表达 / 记笔记，进度自动记忆，与「我的表达」数据互通（阅读页通过同域 iframe 共享 localStorage）。
- **导出**：每日内容可导出 PNG / PDF 卡片（浏览器本地生成，不上传任何数据）。

## 技术栈

- 原生 HTML / CSS / JavaScript，无任何框架、无构建步骤、无后端
- 数据存储：浏览器 `localStorage`（表达 / 进度 / 打卡均留在本地，不上传服务器）
- 第三方库：仅 `html2canvas` + `jsPDF`（导出功能，位于 `libs/`）
- 外部接口：阅读器「点词查义 / 翻译」调用免 Key 公共 API（dictionaryapi.dev / mymemory.translated.net）

## 本地运行

项目为纯静态站，无需安装依赖：

```bash
# 方式一（推荐）：本地服务器
python -m http.server 8200
# 浏览器打开 http://127.0.0.1:8200/
```

直接双击 `index.html` 亦可打开（部分浏览器会拦截本地 iframe，建议方式一）。

## 目录结构

```
english-learning-center/
├─ index.html          首页（导航 + 学习区 + 我的表达 + 复习）
├─ reading.html        阅读积累中心（书籍列表 + 阅读器）
├─ manifest.jsonl      每日内容清单（78 条）
├─ days/               每日学习内容（reading-* / speaking-* / drama-*）
├─ books/              英文原版书（阅读中心素材）
├─ assets/             静态资源（封面图）
├─ libs/               html2canvas / jsPDF
└─ README.md
```

## 环境变量

本项目为纯前端静态站，**无需任何环境变量 / API Key**。若需二次开发对接自有服务，请将密钥放入 `.env` 且确保其已被 `.gitignore` 忽略，切勿提交到仓库。
